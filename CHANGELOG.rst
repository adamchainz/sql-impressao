=========
Changelog
=========

1.13.0 (2026-11-09)
-------------------

* Support Python 3.15.

  `PR #74 <https://github.com/adamchainz/sql-impressao/pull/74>`__.

* Drop Python 3.10 support.

  `PR #78 <https://github.com/adamchainz/sql-impressao/pull/78>`__.

* Include type hints in built wheels, fixing mypy’s “missing library stubs or py.typed marker” error.

  `PR #82 <https://github.com/adamchainz/sql-impressao/pull/82>`__.
  Thanks to 93578237 for the report in `Issue #59 <https://github.com/adamchainz/sql-impressao/issues/59>`__.

1.12.0 (2026-05-14)
-------------------

* Build with frame pointers enabled, preparation for `PEP 831 <https://peps.python.org/pep-0831/>`__.

  `PR #61 <https://github.com/adamchainz/sql-impressao/issues/61>`__.

* Update to sql-fingerprint 1.11.1 (`changelog <https://github.com/adamchainz/sql-fingerprint/blob/main/CHANGELOG.rst>`__).

1.11.0 (2026-02-10)
-------------------

* Update to sql-fingerprint 1.10.0 (`changelog <https://github.com/adamchainz/sql-fingerprint/blob/main/CHANGELOG.rst>`__).

* Ship Windows ARM wheels.

  `PR #50 <https://github.com/adamchainz/sql-impressao/pull/50>`__.

* Stop shipping wheels for 32-bit Linux and Windows.

  `PR #48 <https://github.com/adamchainz/sql-impressao/pull/48>`__.

1.10.0 (2025-11-27)
